# Reinforcement Learning Projects

A collection of reinforcement learning projects covering classical, deep, multi-agent, and neuromorphic approaches.

This repository brings together work on:

- Tabular Q-learning
- Deep Q-Networks (DQN)
- Double DQN
- Multi-Agent Reinforcement Learning
- Synaptic-weight-based learning
- Neuromorphic reinforcement learning
- Hardware-inspired optimization with spintronic synapses

## Repository Structure

### Classical Deep Reinforcement Learning

#### CartPole with DQN
`classical-deep-rl/cartpole-dqn`

Deep Q-Network implementation for the CartPole control problem.

#### FrozenLake with DQN
`classical-deep-rl/frozenlake-dqn`

DQN-based reinforcement learning experiments on the FrozenLake environment.

#### MountainCar with Double DQN
`classical-deep-rl/mountaincar-double-dqn`

Double DQN implementation for the MountainCar environment.
